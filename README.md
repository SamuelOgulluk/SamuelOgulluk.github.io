Samuel Ogulluk - Portfolio Personnel
Code source de mon site personnel et portfolio, accessible à l'adresse https://samuelogulluk.github.io.

Ce projet est une application web présentant mon parcours, mes compétences et mes projets.

Stack Technique
Core : React 19 / TypeScript

Build Tool : Vite

Styling : Tailwind CSS

Animations : Framer Motion & HTML5 Canvas (pour l'arrière-plan interactif)

Déploiement : GitHub Pages (via GitHub Actions)

Fonctionnalités
Bilingue : Support complet EN/FR avec bascule instantanée (Context API).

Design Responsive : Adapté aux mobiles et desktops via Tailwind.

Interactivité : Animation de fond avec particules réactives à la souris (BackgroundAnimation.tsx).

Navigation fluide : Scroll spy pour la navigation active et défilement doux.
